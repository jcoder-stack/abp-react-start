Next steps:
  1. Finish .env: AUTH_CLIENT_ID is required — the client registered in your backend's OpenIddict
     (the notes in .env show how to probe for it). If you skipped the backend URL during init,
     also fill AUTH_ISSUER / AUTH_ABP_BASE_URL and the input in abp.api.config.ts.
  2. jc-abp gen
  3. bun run dev

A self-signed backend certificate (the local ABP default) fails both gen and dev — Node ignores
the OS keychain, so trusting it there is not enough. Export the certificate and put its path in
.env; only that one certificate is trusted extra (needs Node >= 22.15):
  dotnet dev-certs https --export-path ~/.aspnet-dev.crt --format PEM
  then add to .env: AUTH_EXTRA_CA_FILE=~/.aspnet-dev.crt

QueryClient, SSR integration); the scaffold originals are backed up next to them as .bak. To tweak
head tags or bring devtools back, edit those two files directly or pull fragments from the .bak.
